# v2.0.0-beta9 — inverter operation mode check

This is a **pre-release** building on v2.0.0-beta8. It only adds a read-only check: nothing is written to the inverter.

## What's New

### Inverter operation mode

- The integration now reads the inverter's operation mode. For GoodWe ET inverters in direct mode it reads register 47000; otherwise it reads the operation-mode select entity of the GoodWe integration.
- The integration reports the operation mode to the Volcast cloud.
- When the inverter runs in a mode other than General (for example Eco, or a time-of-use schedule set in the manufacturer's app), a Repairs issue is raised. The issue is removed when the inverter returns to General.
- Read-only: no writes to the inverter. Installing or updating does not change any inverter setting.

## Upgrading

Update via HACS and restart Home Assistant.
