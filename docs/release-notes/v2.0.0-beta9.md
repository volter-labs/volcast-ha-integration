# v2.0.0-beta9 — inverter operation mode check

This is a **pre-release** building on v2.0.0-beta8. It only adds a read-only check: nothing is written to the inverter.

## What's New

### Inverter operation mode

- The integration now reads the inverter's operation mode (GoodWe ET family). In direct mode it reads the operation-mode setting register as defined by the goodwe library (47000); only the General value has been verified on hardware so far. Otherwise it uses the state of the GoodWe integration's operation-mode select entity.
- The integration reports the operation mode to the Volcast cloud as General, other, or unknown (not read yet).
- When the operation mode is not General, a Repairs issue is raised. The issue is removed when the inverter returns to General.
- Time-of-use schedules are detected only through the operation mode: a schedule that does not change the operation mode is not detected.
- In entity mode the integration refreshes the operation-mode select entity every poll interval (15 minutes), because the GoodWe integration does not update it on its own. The entity must be enabled.
- In direct mode, if the register read keeps timing out, the integration retries less often (at most once a day) and keeps reporting the last value it read until a read succeeds.
- Read-only: no writes to the inverter. Installing or updating does not change any inverter setting.

## Upgrading

Update via HACS and restart Home Assistant.
