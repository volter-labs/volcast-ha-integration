# v1.7.4 — Event loop and translation fixes

Maintenance release. No functional changes to forecasts or production tracking.

## Fixes

- **Time zone lookups no longer touch the disk on the event loop** — the integration now uses the time zone Home Assistant has already loaded instead of building a new zone object on every call. Entities, the coordinator, the production tracker and the daily reconciler are affected; behaviour is identical.
- **English translations are complete again** — `translations/en.json` was missing the battery charge power field labels and the Repairs entry for production tracking, so users saw raw keys. The file now matches `strings.json`, and a test keeps the two in sync.

## Packaging

- A test workflow now runs on every push and pull request.
