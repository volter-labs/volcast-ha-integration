# v2.0.0-beta1 — Installation discovery (read-only, preview)

This is a **beta release** introducing installation discovery. Existing forecast setups keep working exactly as in 1.7.2; after updating, they also get the 'Installation discovery' sensor and 'Run discovery' button, and discovery runs automatically after each Home Assistant start.

## What's New

### Automatic Discovery Scan

Discovery runs automatically once after Home Assistant starts and again after each integration reload. It scans your installation and adds two entities to your Volcast device:

- **Installation discovery** sensor — a summary of what was found
- **Run discovery** button — manually re-scan anytime

### What Discovery Reads

The scan gathers:

- Which inverter and price integrations are installed in your Home Assistant (device and entity registries)
- Entity names, units, and options from those integrations
- The inverter's host address from its settings (no passwords or other settings data)
- How many days of long-term statistics your energy sensors have
- Sends one UDP broadcast on port 48899 to find Wi-Fi data loggers on your local network

Discovery never connects to, writes to, or changes anything in your inverter or other integrations.

### Privacy & Data Handling

The full discovery result stays in Home Assistant and is visible only in your diagnostics file. Serial numbers, MAC addresses and e-mails are masked in that file (IP addresses are kept). **Nothing is sent to Volcast.**

To share your installation details with support:

1. Go to **Settings** → **Devices & Services**
2. Click **Volcast**
3. Tap the **⋮** (three dots) menu → **Download diagnostics**

### New Setup Option: Discovery-Only

A new "**Discovery only (no account)**" setup flow is available for people without a Volcast account. It enables local installation discovery with:

- No Volcast API key required
- No forecast
- No cloud connection

## For Existing Users

Existing forecast setups keep working exactly as in 1.7.2; after updating, they also get the 'Installation discovery' sensor and 'Run discovery' button, and discovery runs automatically after each Home Assistant start.

## Upgrading from v1.7.2

Update via HACS. No configuration changes required.

### Going Back to v1.7.2

If you'd prefer to revert:

1. **Delete** any "Discovery only (no account)" Volcast entry — v1.7.2 cannot load it
2. In HACS, click **Volcast Solar Forecast** → **⋮** → **Redownload**
3. Select version **1.7.2**
4. Restart Home Assistant
