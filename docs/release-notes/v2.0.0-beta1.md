# v2.0.0-beta1 — Installation discovery (read-only, preview)

This is a **beta release** introducing optional installation discovery — a new, read-only mode for exploring Home Assistant sensors without requiring a Volcast API key or account. Forecast users are unaffected.

## Discovery Mode (NEW)

A new setup flow lets you explore your Home Assistant installation in a Volcast context without authentication:

- **No account needed** — select "Discovery only (no account)" during setup
- **Read-only** — scans your HA Recorder statistics, installation sensors, and responds to a UDP discovery broadcast on port 48899
- **What it gathers**:
  - HA Recorder: daily energy statistics (used to understand your inverter schema and naming)
  - Sensor registry: all entities exposed to Home Assistant
  - Basic device info (hostname, system version, uptime)
- **What it doesn't do** — no data is sent to Volcast; no profiles, passwords, or network settings are accessed; no forecast is generated
- **Diagnostics** — the integration masks hostnames, identifiers, and email addresses in diagnostic reports

### Discovery Sensor & Button

When discovery mode is active:

- **Sensor**: `sensor.volcast_installation_discovery` shows the last discovery scan result
- **Button**: *Run discovery* on the integration device page triggers a scan on demand

The feature is self-contained and invisible to the Volcast cloud — it is purely local to Home Assistant.

## Forecast Users (No Change)

This release does not change forecast behaviour or add new requirements. Existing configurations work unchanged. The discovery setup option is an **alternative** to the standard API-key setup — you don't have to use it.

### Upgrading from 1.7.2

Update via HACS. No configuration changes required.

### Going Back

If you need to revert to v1.7.2:

1. In HACS, navigate to **Integrations**
2. Click the 3-dot menu on **Volcast Solar Forecast** → **Redownload**
3. Select version **1.7.2**
4. Restart Home Assistant
