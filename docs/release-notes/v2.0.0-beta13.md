# v2.0.0-beta13 — Volcast 2.0 beta

This is a **pre-release** for testers of the Volcast 2.0 app. It replaces all earlier 2.0.0 betas. The stable line
(v1.7.2) is unchanged; stay on it unless you were invited to the 2.0 beta.

## What's new in 2.0

- **Account pairing** — connect Home Assistant to your Volcast account by scanning a code in the app; no API key to copy.
- **Live home energy** — readings from your inverter, battery and grid meter are sent to Volcast for the Home and Energy screens.
- **Battery plan and inverter control** — Volcast can follow its price-aware battery plan on supported inverters,
  either directly over the local connection or through the existing Home Assistant integration (e.g. GoodWe).
  Control is off until you enable it in the app.
- **PV-first grid charging** — when the plan charges from the grid, solar production is used first.
- **One production source** — production is reported once per hour from a single source, without duplicates.
- **Signed brand profiles** and an **EV charger preview**.

## Changes in this build

- Account pairing now uses the production Volcast service by default. Leaving the address empty in the pairing
  form (Advanced section) selects it.
- The Advanced address field still accepts another pairing service address (HTTPS), for example one that Volcast
  support gave you.
- Re-pairing an existing entry keeps the entry, its entities and statistics, and switches it to the service it was
  paired with.
- Includes all fixes from earlier betas (control setup, pairing reliability, sensor resilience on network errors).

## Upgrading from an earlier 2.0.0 beta

Update in HACS, restart Home Assistant, then pair again from the app (Settings → Home Assistant). Your forecast
entities and history are kept.
