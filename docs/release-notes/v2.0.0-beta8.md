# v2.0.0-beta8 — battery hold during EV charging

This is a **pre-release** building on v2.0.0b7. There are no integration code changes in this build; it only extends test coverage and bumps the version.

## What's New

- Battery hold during EV charging now arrives in the plan after a realtime ping. While an electric vehicle is charging, the Volcast cloud can turn the current plan slot into a `hold` slot (no power, state of charge or export targets). The integration refreshes the plan when the content of a slot changes, even if the plan id stays the same, and maps `hold` to the inverter's standby mode with zero battery power (for GoodWe ET: `battery_standby`).
- Requires the `ha_signals` and `ev_battery_guard` flags to be enabled on your Volcast account.

## Tests

- New regression test: a plan with an unchanged id but different slot content is accepted again; an identical repeat is ignored.
- New regression vectors for the `hold` slot mapping to standby with zero power.
