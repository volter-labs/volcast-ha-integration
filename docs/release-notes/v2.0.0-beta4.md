# v2.0.0-beta4 — Control through the GoodWe integration

This is a **pre-release** building on v2.0.0b3. The only functional change is that control through the GoodWe integration (entity mode) is now available.

## What's New

### Control through the GoodWe integration

The entity mapping for GoodWe ET/EH/BT/BH inverters is now marked **verified**: the write path through the `goodwe` integration was confirmed on a live inverter. Volcast now writes its plan (mode and power settings) to the inverter through that integration's entities.

Requirements:

- The HACS **GoodWe Inverter (experimental)** integration installed and configured in Home Assistant
- Consent given in the Volcast app
- The Volcast control switch turned on
- **Options → Inverter control** set to **Through the inverter integration**

All safety rules from v2.0.0b3 apply unchanged: daily write limit, read-back of written values, drift pause when you change a setting yourself, and return of control to the inverter's own settings when consent is withdrawn, the switch is turned off or the entry is removed.

## Direct control stays disabled

Direct control over the local network (writing to registers) is **still not available**: both built-in direct profiles (GoodWe and Deye) remain draft. The read-only test connection works as in b3.

## Known Limitations

The known limitations from v2.0.0b3 still apply. In particular, **selling needs a house-consumption reading**: if there is no usable house-consumption sensor and no earlier valid reading since Home Assistant started, a sell slot exports nothing (0 W). Make sure the inverter's house-consumption sensor is available.

## Upgrading and Going Back

Update via HACS and restart Home Assistant. To go back to v2.0.0b3, turn off the Volcast control switch first and wait until the status sensor shows that the inverter was returned to its own settings.
