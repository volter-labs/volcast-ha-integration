# v2.0.0-beta15 — Volcast 2.0 beta

This is a **pre-release** for testers of the Volcast 2.0 app. It replaces all earlier 2.0.0 betas. The stable line
is unchanged; stay on it unless you were invited to the 2.0 beta.

## What's new

- **Production after a data gap** — when Home Assistant or the inverter integration was unavailable for a while (a
  restart, an update, an offline inverter), the energy produced during the gap is no longer attributed to a single
  hour. The plugin remembers the last known counter value across silent periods and, after the gap, reports the
  period the reading covers (up to 36 hours). Once a day is closed, it also sends that day's total calculated from
  Home Assistant statistics, but only when the statistics for the day are complete, so daily production stays
  correct. No action is required.
- **Direct connection: the inverter is found again at a new address** — when the inverter on a direct connection
  stops answering (for example after its network address changed), Volcast searches the local network for it, first
  at once and then again after 5 minutes, 15 minutes and every hour. It re-attaches only when the device identity
  matches exactly: the serial-number-based fingerprint, the profile and the transport. Only the network address of
  the connection is updated. If no device matches, nothing is changed.
- **Repair issue: inverter unreachable** — while a direct connection gets no response from the inverter, Volcast
  shows a repair issue. It names no address, explains that the search runs automatically and points to the manual
  search in the options (Installation details). The issue clears when readings return.
- **Repair issue: inverter left in a forced mode** — when the direct connection is lost while the inverter is in a
  mode set by Volcast (for example charging the battery from the grid or selling energy), a repair issue warns that
  the inverter may stay in that mode until the connection is restored, and tells you to set the normal operating
  mode in the manufacturer's app or on the inverter's display if it does not come back. Texts are available in all
  13 languages.

## For testers

Switch control off before downgrading to an earlier beta.

## Upgrading from an earlier 2.0.0 beta

Update in HACS and restart Home Assistant. Your forecast entities and history are kept.
