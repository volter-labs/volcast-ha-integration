# v2.0.0-beta6 — GoodWe direct control verified

This is a **pre-release** building on v2.0.0b5. It marks direct control of a GoodWe ET/EH/BT/BH inverter over the local network (registers via the inverter's Wi-Fi module, UDP) as **verified**. After updating, the "Direct" control mode is offered for GoodWe without the test-connection step.

## What's New

### GoodWe direct control is available

- The built-in GoodWe profile is now verified for the register path. A GoodWe inverter found on the network can be set to the Direct control mode in the options flow (and from the Volcast app when pairing).
- The safeguards added in the previous builds apply to every register write: write verification by read-back, a daily write limit, return to the inverter's own settings when control is switched off or the plan is lost, and a refusal to write when the safety settings cannot be read.
- Deye stays a draft: only the read-only test connection is available for it, and no register writes are made.

### Exclusive use of the Wi-Fi module

The Wi-Fi module of a GoodWe inverter serves one client reliably. Volcast must be its **only** client: the manufacturer's app or cloud link, other Home Assistant integrations and other energy controllers talking to the same module cause timeouts and mismatched replies. Volcast refuses an address that another enabled integration entry already uses.

## Writes start after you update and consent

Writes to the inverter start only if Direct control mode is selected for the entry and control is switched on. Updating alone does not change an existing setup that uses entity mode or has control off. Switching the control switch on is your consent to writes.

## Known Limitations

The known limitations from v2.0.0b4 and v2.0.0b5 still apply. In particular, **selling needs a house-consumption reading**: if there is no usable house-consumption sensor and no earlier valid reading since Home Assistant started, a sell slot exports nothing (0 W).

## Upgrading and Going Back

Update via HACS and restart Home Assistant. To go back to v2.0.0b5, turn off the Volcast control switch first and wait until the status sensor shows that the inverter was returned to its own settings.
