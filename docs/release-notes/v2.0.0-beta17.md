# v2.0.0-beta17 — Volcast 2.0 beta

This is a **pre-release** for testers of the Volcast 2.0 app. It replaces all earlier 2.0.0 betas. The stable line
is unchanged; stay on it unless you were invited to the 2.0 beta.

## What's new

- **Nightly reconciliation after a data gap** — hours covered by a reading sent after a data gap are no longer re-sent by the nightly reconciliation, so they keep the value reported for the whole gap instead of being overwritten by a partial one. No action is required.
- **Deye three-phase hybrids through the Solarman integration** — SUN-xK-SG04LP3 and SG01HP3 hybrids set up with the Solarman integration (davidrapan/ha-solarman) are now matched by the Deye profile, so state of charge, battery temperature, PV, battery, grid and load power and the grid energy counters are read from that integration's sensors. The profile is a draft: reading only, no control, and none of the integration's numbers, selects or switches are used. The archived StephanJoubert Solarman integration is not covered.

## Upgrading from an earlier 2.0.0 beta

Update in HACS and restart Home Assistant. Your forecast entities and history are kept.
