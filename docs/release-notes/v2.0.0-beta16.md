# v2.0.0-beta16 — Volcast 2.0 beta

This is a **pre-release** for testers of the Volcast 2.0 app. It replaces all earlier 2.0.0 betas. The stable line
is unchanged; stay on it unless you were invited to the 2.0 beta.

## What's new

- **Read-only integrations (sensors only)** — some integrations are described by a profile that uses sensors only. Volcast reads state of charge and PV, load, grid and battery power from them and never writes to them: no numbers, selects or switches are used, and control is not offered for such an integration.
- **New read-only integrations from the profile feed** — a profile for this kind of integration arrives through the profile feed, so no plugin update is needed. After it arrives, a paired Volcast entry that does not use direct control re-checks its inverter profile. If the read-only integration becomes the chosen profile, the existing "test profile available" repair notice appears. Confirming the notice only dismisses it; reading starts after the Volcast integration is reloaded (or Home Assistant restarts). No notice appears when another inverter in the home is already matched by a verified profile or by a profile that maps its own integration, because that profile stays chosen.
- **Frozen readings are not sent** — in entity mode, if the source keeps reporting identical load and grid values for 30 minutes, Volcast stops sending inverter readings until a value changes. Diagnostics shows this state. Known limitation: while inverter readings are unavailable or frozen and there are no prices to send, EV charger data is not sent either.
- **Monitor-only EV chargers** — chargers exposed as sensors only (status, power, energy, no control entities) can be added as monitor-only chargers. Their sessions are reported; the charger is never controlled.
- **EV charger detection** — devices of an inverter integration are no longer offered as EV chargers when they belong to a read-only integration or have a battery state-of-charge sensor.
- **Buy and sell price entities** — two new sensors, "Buy price" and "Sell price", show your current price per kWh in your market's currency, exactly as the Volcast planner and app use it (energy, variable distribution charges and VAT; fixed monthly or daily fees are not included). Each has today's and tomorrow's prices as an attribute list for charts and automations; tomorrow appears once prices are published. The state switches at every price window boundary.
- **Who gets them** — accounts on the Plan or Automat tier with a paired Volcast cloud connection and a saved plan that has at least one priced window today or tomorrow. Accounts whose prices come from Home Assistant itself do not get them (the entities stay unavailable). The entities become unavailable when the cloud reports no prices for the account (for example after the tier ends); a temporary cloud problem does not clear them.
- **Requires the updated Volcast cloud** — the integration now asks for schedule contract version 5; on an older cloud the price entities stay unavailable and everything else works as before.
- **Huawei SUN2000 MAP0 through the Huawei Solar integration** — three-phase SUN2000 MAP0 hybrids set up with the Huawei Solar integration are now matched by the Huawei profile, so state of charge and PV, battery and grid power are read from that integration's sensors. The profile is a draft: reading only, no control. House load has no sensor in that integration and is calculated by the Volcast cloud from the other readings. The battery temperature sensor is disabled by default in the Huawei Solar integration; enable it there if you want it read.
- **Time zone lookups on the event loop** — the integration takes the time zone from Home Assistant instead of loading it itself, which removes the "blocking call" warning some installations logged at start-up (the same fix as in the stable line).

## For testers

Switch control off before downgrading to an earlier beta. After a downgrade the two price entities stay in the
entity registry as unavailable; remove them by hand if you do not plan to update again.

## Upgrading from an earlier 2.0.0 beta

Update in HACS and restart Home Assistant. Your forecast entities and history are kept.
