# v2.0.0-beta14 — Volcast 2.0 beta

This is a **pre-release** for testers of the Volcast 2.0 app. It replaces all earlier 2.0.0 betas. The stable line
is unchanged; stay on it unless you were invited to the 2.0 beta.

## What's new

- **Write-right certificates for feed profiles** — a device profile delivered by the profile feed can write to the
  inverter only with a certificate that was signed offline. Without a valid certificate a feed profile stays
  read-only, whatever its status says.
- **Invalid profiles are skipped one by one** — an invalid profile in the feed is skipped; the other profiles in the
  feed still apply. Earlier, one invalid profile rejected the whole feed.
- **Engine version for profiles** — a profile can declare the minimum engine version it needs (`min_engine`). A
  profile that needs a newer engine than this release is skipped instead of misbehaving.
- **Faster feed updates** — the plan response can hint that the profile feed has changed. The integration then checks
  the feed, at most once every 15 minutes.
- **Three trusted feed signing keys** — the integration accepts feeds signed with any of the three trusted keys.
- **Battery control with a remote-control switch and separate power limits** — the profile format and the control
  engine now support batteries that need a remote-control switch to be turned on before the mode is set, and
  batteries with separate charge and discharge power set-points. This is opt-in per profile; profiles that do not
  declare it behave as before.
- **Repair and onboarding messages for control** — when the inverter control entities are disabled or missing, or
  when the device rejects control writes, Volcast shows a repair issue and a matching onboarding message. The issue
  clears once the cause is fixed. Texts are available in all 13 languages.

## Fixes from the earlier stage of this release

- Production sensors are optional in the setup form; they can be left empty.
- The PV energy sensor help text states that the sensor may be a daily or a lifetime counter.
- Price sources:
  - sell prices are paired across nested interval grids (for example a quarter-hour sell series with an hourly buy
    series);
  - a finer sell series is averaged over each buy interval;
  - the price block is trimmed to the intervals that have both buy and sell prices, or held while a sell price action
    has no fresh result, instead of sending `sell: null`;
  - price integrations are configured from one shared list of integrations.

## Behaviour change

- An owner export limit of 30 kW or more (for example a 32-bit "no limit" value) is now restored unchanged when
  control is handed back. Earlier, such a value blocked all control commands.

## Upgrading from an earlier 2.0.0 beta

Update in HACS and restart Home Assistant. Installations on the previous beta keep the last profile feed they
received until they are updated, because that beta does not understand the new profile fields. Your forecast
entities and history are kept.
